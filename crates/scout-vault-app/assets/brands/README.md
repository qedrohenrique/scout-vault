# Brand icons

SVGs from [Simple Icons](https://simpleicons.org) (license [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md)),
copied unchanged. The brands belong to their owners; Scout Vault uses the icons only to
identify vault items, without any affiliation or endorsement.

To add a brand: copy `icons/<slug>.svg` from the `simple-icons` package into this folder and
add a `brand!(...)` line in `src/item_icons.rs`, with the site's name and domains.
